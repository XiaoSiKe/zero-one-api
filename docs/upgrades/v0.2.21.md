# v0.2.21 integration contract

Zero One synchronizes [Sub2API v0.2.21](https://github.com/Wei-Shaw/sub2api/releases/tag/v0.2.21) at `10ba8f9b4dc2e6023d4a9879ab77b21841babd10`, including the changes since v0.2.19 through v0.2.20. The [reproducible change map](v0.2.21-change-map.json) records the upstream delta against the two-parent product integration. The tagged source still reports 0.2.20, so Zero One sets the server version to 0.2.21.

## Gateway, billing and administration

- Adopt the upstream adaptive request-body memory budget, bounded read/write behavior, atomic refresh-token rotation, scheduling fixes, Claude Fable and Mythos 5.2 support, GPT Image 2.6 variants, and OpenAI 30-minute and 12-hour cache-write accounting. The documented budget key is `gateway.request_body_memory_budget_bytes`.
- Retain Zero One's site-level semantic first-token timing and separate attempt timing. The Anthropic compatibility paths share the existing buffered response assembler and use the upstream stream failure state to keep partial usage and protocol errors consistent.
- Keep one usage SQL column order for all insert paths and the read projection. Persist both new TTL buckets alongside the existing upstream-declared cost evidence. Keep the generic GPT Image 2.5 alias. Rebuild cached authentication snapshots using v28, which retains group pricing isolation and includes the privacy requirement and new cache-write prices.
- Scoped administrator keys keep the existing JWT and step-up lifecycle, including JWT-only manual affiliate binding. Full-access compatibility mode requires explicit confirmation to enable. Updates to existing full-access keys require an explicit mode so the older Console editor cannot silently change it. See [the key guide](../admin-api-keys.md).

## Approved UI and configuration

The recovered website, Console and Infinite Canvas keep the existing production assets. The desktop and mobile version fixtures obtain their version from the server VERSION file. The newer upstream account and settings pages, TTL pricing controls, and MCP consent and connection pages are outside this approved UI. Existing Console pricing forms do not submit the 12-hour field. Use the pricing API when creating or editing cards that use an explicit 12-hour price. Management MCP stays disabled by default. See [the MCP guide](../mcp.md).

The Go toolchain and image builders use 1.27.4 to address [GO-2026-6859](https://pkg.go.dev/vuln/GO-2026-6859). The maintained Console build updates Vite, follow-redirects, glob and minimatch to the versions selected in the lockfile.

## Database compatibility

The upstream SQL is retained byte-for-byte. The ledger identifies migrations by complete filename, including both files with prefix 249.

- `249_add_usage_logs_api_key_cost_index_notx.sql` builds a covering index on `usage_logs` concurrently. Allow time for the index build on large databases.
- `249_mcp_oauth.sql` adds OAuth client and grant storage.
- `250_openai_cache_write_ttl.sql` adds zero-default TTL counters and nullable cache prices. The migration preserves historical bills and configured generic cache prices.

Any future production release follows the [coherent release procedure](../OPERATIONS.md#release-and-rollback) and its restore, migration and smoke checks.
