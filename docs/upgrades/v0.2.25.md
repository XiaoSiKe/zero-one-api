# v0.2.25 integration contract

Zero One integrates [Sub2API v0.2.25](https://github.com/Wei-Shaw/sub2api/releases/tag/v0.2.25) at `348997267d756eab5729bb6b78a275a15d18796a`. The [change map](v0.2.25-change-map.json) records the two-parent merge against v0.2.24. The upstream tag still embeds 0.2.24, so Zero One sets the server version to 0.2.25.

## Gateway and account administration

- Administrators can configure API Key Provider Account header overrides with the gateway user, key, group or request ID. The gateway expands configured templates for the current request, and diagnostics omit fixed text from mixed values. Grok OAuth header overrides continue to support static values.
- Groups may be returned by `GET /v1/sub2api/billing?include=group` for a key that has an assigned Group. Administrators can preview the upstream group name and description and apply them to a Provider Account. Automatic synchronization is opt-in and depends on scheduled probing. Rate synchronization remains a separate setting.
- OpenAI passthrough applies error passthrough rules and preserves sanitized structured errors for clients that handle encrypted-content and context-limit failures. The release keeps Zero One's existing site-level and attempt-level timing, customer debits and request-time Provider Account cost.

## Console and data

The maintained Vue account editors and error detail include the new controls. Production Edge serves the existing Approved UI Snapshot. Use the administrator API for new configuration that the recovered Console does not expose.

The release adds no SQL migrations. Group synchronization uses the existing Provider Account settings and stays disabled until enabled for that account. The [coherent release procedure](../OPERATIONS.md#release-and-rollback) still requires a verified restore, an exact migration ledger comparison and business data fingerprints.
