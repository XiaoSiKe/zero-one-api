## Integration and preserved behavior

The Gemini and Antigravity gateway services own Gemini 4 Argon, thinking configuration, stream summaries, native tool parts and account endpoint discovery. The existing pricing owner resolves exact tier entries before normalized base prices, including Claude 5.5 tiers. Keep the product's explicit Group/account long-context gates, request-time upstream cost evidence, Site First Token, generic gpt-image-2.5 and explicit-cache resource identity and storage-cost scope.

OpenAI's scheduler and public catalog share the subscription retirement policy: GPT-5.5 is unavailable through ChatGPT OAuth/SetupToken and shadow accounts after upstream retirement, while API Key accounts and explicit mappings to supported replacements remain valid. Do not silently rewrite customer model mappings. Composite OAuth ambiguity is rejected before selecting an incompatible protocol. Responses objects receive a consistent created_at without changing semantic first-token bookkeeping.

Payment providers confirm successful notifications before the existing fulfillment transaction. Unsupported order types fail before crediting. Refund deduction holds and terminal failure compensation use the existing payment owner and transactions; they do not recalculate past balances, orders or affiliate records. Stripe source routes read the client secret from the matching local recovery snapshot rather than a URL parameter.

Account editor changes enter EditAccountEditorPanel behind the existing public wrapper; AccountTestModal remains a forwarding wrapper. Regression checks exercise persisted OpenAI API-key web-search settings, legacy booleans and resetting to the global default through the public editor. Retired duplicate dialogs and Channel Monitor V2 stay absent. Preserve published production asset bytes and the approved layout. Source-only UI changes, including Stripe URL handling and account filter layout, are not represented as changes to the frozen production UI. VERSION is explicitly 0.2.17 because the upstream tag still contains 0.2.16.

## Data and release acceptance

This release adds no SQL migration files. Require the complete existing migration ledger, original business-column fingerprints, row identities, balances and historical usage to remain unchanged. Restore fresh encrypted off-host PostgreSQL, Redis and deployment-state archives. Exercise migration-only repeatability and new/old/new application compatibility against the restored populated database before production cutover, then compare the final stopped-write snapshot again.

Require complete make test, source/frozen compatibility builds, policy/security checks and pinned Linux Chromium before publishing the PR. Require protected PR checks, exact-main product/security evidence and same-SHA immutable Backend/Edge digests before deployment. Use release-control.py in Backend-first order with its watchdog and rollback path; preserve PostgreSQL/Redis containers, persistent mounts, business secrets and the direct tunnel. Run dedicated limited smoke requests and observe at least 30 minutes. Actual backup, cutover, smoke and observation results belong in the restricted release record outside Git. Planned checks are not passed evidence.
