# v0.2.11 integration and release contract

The Upstream Baseline is `v0.2.11` at `96f4c115c9749078f90cbf210a01d39baf3f53b6`. The pre-upgrade product is `ce899e5ae03cf4265855022a54d2d1ef5b5c5a68`; the recorded two-parent merge is `9d9aecbb860b8bceb1ae0c031a7c77f08c7b3d83`. The deterministic [change map](v0.2.11-change-map.json) covers all 268 upstream paths since v0.2.8. This target remains fixed if another release appears during verification.

The backend adopts GPT-6.1 Sol and Claude Sonnet 5.5 support, Astra Ultrafast pricing, Claude reset-credit redemption, API Key creation limits, balance inflight reservations, provider stream/cache accounting fixes and Claude Code fallback routing. Public authorization, requested/upstream model attribution, saved upstream cost evidence, affiliate ownership, redemption claims and active V1 monitoring keep their existing product contracts.

## Integration ownership

The existing `anthropicBufferedResponse` remains the single owner of buffered Anthropic event assembly and usage merging. Its shared usage merger adopts the upstream cache aliases; both Responses transports reuse it. Streaming conversion synchronizes the same normalized buckets. The native transport keeps its idle timeout and signed-thinking model handling without duplicating buffered billing assembly. Customer long-context pricing retains the product group-and-account AND gate. The upstream account-cost regression is adapted to that preserved customer gate, with all four group/account combinations, while Provider Account cost follows only the account switch. The dashboard snapshot retains explicit refresh bypass while passing the upstream metric to its existing service/cache interfaces. Dependency injection adds the reset-credit provider without reviving retired passive monitoring.

The Approved UI Snapshot and published frontend namespaces remain unchanged. Upstream frontend presentation is deferred, including the new reset-credit cell and remote Codex configuration controls; backend/API support does not claim those controls are delivered. Retired Codex API sources remain absent. Shared API types adopt compatible fields. The frozen build verifier compiles current caller source into a temporary tree and fingerprints all frozen assets before/after. It no longer compares evolved API source output with historical published output: v0.2.8 source already differs from its v10 namespace at network-error metadata. Historical bytes remain protected by the separate UI/upstream byte locks. New frozen-source differences are registered under Console Skin. The upstream tag carries `0.2.10` in `VERSION`; the existing metadata-alignment hotfix reports `0.2.11`.

## Runtime and data compatibility

There are **no new SQL migrations** between v0.2.8 and v0.2.11. All prior full-filename migration records must remain identical. Runtime startup, repeat migration-only execution and old/new application compatibility still require a real populated backup restore. No user, key, balance, payment, usage, affiliate or deployment secret may be rewritten by the upgrade.

API Key creation now defaults to at most 200 active keys per user and 60 creations per hour. Existing keys remain valid and are not deleted; either configured limit accepts zero to disable it. Balance inflight reservations default on, hold estimated cost until asynchronous billing finishes, renew long-lived requests and release on cancellation/drop/failure. Low-balance concurrent requests can be rejected earlier; the pre-existing balance and pricing contracts remain authoritative. These are the upstream's intentional new admission rules, rather than data migrations.

The existing one-time off-host backup procedure remains available; this upgrade does not create a recurring schedule. The release controller must compare original business columns and migration records before and after the migration-only phase, preserve PostgreSQL/Redis identities and mounts, switch Backend before Edge, run limited dedicated-user model probes and observe for at least 30 minutes.

Security verification also updates Axios to 1.20.0, DOMPurify to 3.4.16 and the two brace-expansion branches to 1.1.21/2.1.7. The package manifest, lockfile and pnpm compatibility settings carry the same patched versions; no audit exceptions are introduced. The inflight retained-memory regression runs its unchanged 20,000-model workload and 8 MiB budget in a dedicated test subprocess, isolating process-wide heap measurement from other service-test workers.
