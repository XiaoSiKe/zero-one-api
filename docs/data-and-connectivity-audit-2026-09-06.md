## 连接错误归因

检查窗口内，本站 503 主要是“上游暂时不可用”，上游 502/503 集中在 gpt-5.4 和 gpt-5.6 系列；同时存在用户余额/额度拒绝以及模型或分组配置拒绝。日志条数可能包含同一请求的多个上游尝试，运营统计必须按 `request_id` 去重后再计算受影响请求和用户。

V1 状态只证明某个监控配置的 endpoint、凭据、模型及 challenge 在最近一次检测中成功。它不能证明其他模型可用，也不能证明真实 User 能通过本站完整链路。V2 使用真实请求聚合；其覆盖深度、`data_through` 和聚合延迟必须与健康分数一起读取。

## 覆盖与限制

本轮检查了用户、API Key、Provider Account、Group、用量、消费聚合、Redeem Claim、Subscription、Affiliate Attribution、监控水位与近期错误分类。余额、兑换和邀请的并发事务由现有接口级测试继续保护。

没有修改生产配置或业务数据，也没有自动重算历史账目。生产仍运行较旧源码；本轮代码合入 main 后仍需通过正式发布流程部署，才能在线验证新刷新语义和监控分类。
