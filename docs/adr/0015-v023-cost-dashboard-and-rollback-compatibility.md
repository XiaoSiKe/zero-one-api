# ADR 0015：v0.2.3 成本、仪表盘与回滚兼容

状态：已接受。取代 ADR 0010 的当前成本展示口径，并扩展 ADR 0012 的管理员仪表盘展示；两份旧记录继续解释不可变历史资源和日期浮层。

## 成本口径

管理员账单、账号统计、模型／分组／端点统计与仪表盘统一使用账单保存的原生账号成本：

`COALESCE(account_stats_cost, total_cost) × COALESCE(account_rate_multiplier, 1)`。

零倍率和零成本是有效值。缺少历史账号倍率时按原生默认 1 倍处理，不显示“待确认”，也不使用当前账号配置回算旧账。客户消费继续读取 `actual_cost`，标准金额继续读取 `total_cost`。

`upstream_rate_multiplier`、旧聚合列和探测配置继续保留，用于历史兼容、调度和旧镜像回滚。当前报表不读取它们；兼容聚合列写入同一原生成本，避免形成第二套成本规则。

## 管理员仪表盘

- 用户卡片主数字是未软删除的全部用户数，包含 Administrator；副文案显示今日新增。用户 ID 只表示数据库身份，不解释为用户数量。
- 今日消费和今日 Token 卡片仍固定表示应用时区中的今天。默认日期范围也是今天、按小时。
- 时间控件同时驱动实际消费与总 Token 两张趋势图。消费使用美元两位小数；Token 始终使用 M 或 B 两位小数，提示保留输入、输出和缓存明细。
- 趋势复用 `snapshot-v2` 的 `actual_cost` 与 `total_tokens`，不增加财务接口。完整缺失桶补零，未来桶不生成；失败保留上次成功结果并标记未更新。

## v0.2.3 与回滚

上游 `model_allowlist` 是规范分组字段。迁移 237 保留 `models_list_config`，并通过数据库触发器同步新旧写入；一次请求同时提交不同值时由管理接口和数据库拒绝。当前生产所有白名单开关保持关闭，迁移不自动开启模型限制。

迁移后的数据库必须同时通过 v0.2.3 和发布前 v0.2.1 镜像的读写演练。旧列只能在确认不再需要应用回滚后由新的 ADR 退役；本次发布不得删除它。

## 测试用户清理

测试用户清理不是应用迁移。工具默认只预览，并固定检查 ID 300、302 的来源、软删除状态、余额、充值和所有外键／已知审计引用。任一条件变化即终止；有账单、兑换、邀请、订阅、密钥或审计记录的用户不物理删除。
