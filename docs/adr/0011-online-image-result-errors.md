# ADR 0011：在线生图的结果与错误边界

状态：已接受。修复用户反馈的“接口没有返回可预览的图片”误报，保留既有生图与计费流程。

## 决策

非流式 Images 请求可通过前导空白保持连接。第一次保活会提交 HTTP 200；之后的上游失败仍以标准 JSON `error` 返回，HTTP 状态不能单独证明生图成功。

在线生图 API 模块统一解析普通生图、参考图编辑和模型列表的网关响应。HTTP 非成功状态或响应中的 `error` 都拒绝为错误，并保留公开错误信息、错误码、HTTP 状态与 `X-Request-Id`。无效 JSON 使用固定异常消息，不展示原始响应正文。请求取消和传输错误继续向调用者传播。

生图成功响应必须包含图片数组，图片条目须具有字符串 Base64 或 URL；保留现有 MIME、输出格式和修订提示词。空数组表示本次没有图片，结构异常表示响应失败。前端不猜测额外供应商响应格式，也不自动重发可能已产生费用的生成请求。

结果区明确显示本次失败原因，并保留之前成功生成的图片和历史记录。只有有效且非空的图片结果写入成功历史；失败和空结果均不写入。模型列表和生图页面继续使用现有鉴权及错误展示机制。

## 维护与保护

响应解析由 `frontend/src/features/online-image/api.ts` 维护，结果展示由现有 `ImageGenerationView.vue` 维护；后端保活和故障转移契约保持不变。恢复版通过 `online-image-v14` 发布，旧资源 URL 保留，构建与壳层边界遵循 [ADR 0004](0004-approved-ui-snapshot-at-edge.md)。源码、测试和本记录逐文件加入二开保护。

API 测试覆盖保活后的错误、参考图编辑、HTTP 错误、正常图片、空数组和异常响应；页面测试覆盖失败提示与成功历史边界；固定 Linux 桌面和手机浏览器验证实际恢复版资源及重新加载后的历史记录。
