# ADR 0021：显式缓存存储费的上游成本证据

状态：已接受。细化 ADR 0017 在 v0.2.16 Gemini 显式缓存中的应用。

Gemini 缓存创建和续期新增按 Token-hour 计量的存储费。现有上游声明只证明 Token 调用范围，不能证明存储费或含存储费的混合金额。包含正数 `CacheStorageTokenHours` 的账单保存 `billing_mode=cache_storage`；共享写入路径因此不冻结 Token 范围的上游倍率，现有成本解析器返回金额 `null` 与 `unsupported_billing_scope`。不使用本地倍率或后来的声明补算，不重写历史记录。

客户实际扣费、官方存储价、渠道定价、订阅和 Key 额度预留仍使用新增缓存计费 owner 的实际计算结果；记录的报告范围不能改变扣费。`cache_storage` 是账单报告范围，不是可配置的渠道计费模式。Console 源码通过已有计费标签 owner 呈现该范围；生产已发布资产保持其不可变边界。

验证覆盖纯存储和 Token 与存储混合账单，穿过计费模式、请求时声明与成本读取接口，并断言客户扣费不变。缓存创建、续期、删除、资源归属和修改租约沿用同一新增服务及其上游回归测试。
